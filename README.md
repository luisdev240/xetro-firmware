# Xetro — site prêt pour GitHub Pages

Le site, le flasheur, le firmware Xetro Dualboot + IA et sdcard.zip sont inclus.

1. Crée un dépôt public sur GitHub.
2. Add file > Upload files : envoie tout le CONTENU de ce dossier, avec index.html à la racine et les dossiers assets/ et firmware/.
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.

Le fichier .nojekyll est inclus. Aucune compilation n’est nécessaire.
Le flash USB nécessite Chrome ou Edge sur ordinateur, en HTTPS.
Le pack SD est proposé après le flash. Chaque utilisateur configure sa propre clé Groq.

Site : https://xetro-tembed-luis.purplepig8192.chatgpt.site
Projet d’origine : https://github.com/Filip1x3/Momentum-Firmware-ESP32-Port

## Navigateur Android et Windows

Après un flash réussi, la dernière étape propose le pack SD, l’APK Android et l’EXE Windows. Télécharge puis ouvre l’application choisie. Le T-Embed et le téléphone ou PC doivent être sur le même Wi-Fi ; garde l’application visible ou ouverte pendant la navigation.

Applications : https://github.com/luisdev240/xetro-firmware/releases/tag/navigateur-v1.0.0

## Explorer Xetro

Modèle 3D interactif avec vue éclatée et apparences minéral/carbone, galerie des captures, installation guidée, mise en page mobile et animations respectant la réduction des mouvements.

## Langues du firmware

Dans le flasheur, choisis français, anglais, espagnol, italien, portugais ou chinois simplifié avant la connexion USB. Le fichier de firmware correspondant est vérifié par SHA-256 avant écriture. La langue concerne les menus principaux, le navigateur et le chat IA. Bruce et les applications tierces gardent leur langue d’origine. Les six parcours ont été testés avec un flash simulé ; le flash et le fonctionnement des six variantes sur le matériel restent à vérifier.
