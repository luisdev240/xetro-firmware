# Xetro — site prêt pour GitHub Pages

Le site, le flasheur, le firmware Xetro Dualboot + IA et sdcard.zip sont inclus.

1. Crée un dépôt public sur GitHub.
2. Add file > Upload files : envoie tout le CONTENU de ce dossier, avec index.html à la racine et les dossiers assets/ et firmware/.
3. Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.

Le fichier .nojekyll est inclus. Aucune compilation n’est nécessaire.
Le flash USB nécessite Chrome ou Edge sur ordinateur, en HTTPS.
Le pack SD est proposé après le flash. Chaque utilisateur configure sa propre clé Groq.
